# ยิงเป้าแก๊งเพื่อน (Carnival Shooter by Luffy)

เกมยิงเป้างานวัดบนเว็บ: อัพโหลดรูปเพื่อนได้ไม่จำกัด แล้วเพื่อนจะกลายเป็นตัวการ์ตูนที่วิ่ง เต้น และทำท่ากวนๆ บนราวเป้า ยิงจุกก๊อก 5 นัด โดนอย่างน้อย 3 นัดรับรางวัล

## ฟีเจอร์

- **อัพโหลดรูปเพื่อนไม่จำกัด** — รูปหน้า รูปเต็มตัว หรือรูปหมู่ (แยกทุกคนให้อัตโนมัติ) ถ้าหาหน้าไม่เจอ แตะเลือกหน้าเองได้
- **ชุดจริงจากรูปเต็มตัว** — ตัดหัว ลำตัว แขน ขา จากรูปมาทำเป็นหุ่นเชิด ถ้ามีแค่หน้า จะใส่ตัวการ์ตูนให้
- **ท่าทางกวนๆ** — วิ่ง มูนวอล์ค ฟลอส ส่ายสะโพก ทำท่าไก่ แลบลิ้น พร้อมคำแซวภาษาไทย (มีเสียงพูด)
- **ยิงด้วยตา** — ใช้กล้องหน้า เล็งด้วยการมอง/หันหน้า และหลับตาข้างที่เลือก (ซ้ายหรือขวา) เพื่อยิง มีเป้าแสดงจุดที่มองอยู่ และ Calibrate ใหม่ได้ทุกเมื่อ
- **ทุกอย่างประมวลผลในเครื่อง** — รูปและภาพจากกล้องไม่ถูกส่งออกไปไหน (ใช้ MediaPipe ในเบราว์เซอร์) รูปเพื่อนเก็บใน IndexedDB
- เล่นออฟไลน์ได้ (PWA) รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์

## พัฒนา

```bash
npm install
npm run dev      # เปิดเซิร์ฟเวอร์พัฒนา
npm test         # unit tests (กติกาเกม, ตรวจจับการหลับตา, regression ของสายตา, mask)
npm run build    # type-check + build ไปที่ dist/
```

โมเดล AI อยู่ใน `public/models/` ส่วนไฟล์ WASM ของ MediaPipe จะถูกคัดลอกจาก `node_modules` อัตโนมัติก่อน `dev`/`build`

Push เข้า `main` จะ build และ deploy ขึ้น GitHub Pages อัตโนมัติ
